## Capture decisions that affect real work

Record the audience and product promise, voice principles, approved name and logo files, color values with accessible pairings, type choices, spacing guidance, and examples of interface or editorial use. Include rules for light and dark backgrounds, minimum logo size, and what not to alter.

Keep guidance operational. A contributor should be able to answer “which logo file should I use?” or “how should this error message sound?” without interpreting a mood board. Link to source files and identify who owns updates.

## Keep the system proportional

A small product usually needs a compact reference rather than a large brand book. Review it when product positioning changes or contributors repeatedly make the same mistake. The supplied AI-generated brand-guideline image is only an illustrative seed; it is not an authoritative design standard and should not be copied. Check color contrast and user interface requirements against accessibility guidance, and test the brand system at real sizes and contexts.

## Check the core path

Choose the most important journey and complete it using only a keyboard. Confirm visible focus, logical order, working skip links, and no keyboard traps. Use semantic headings, landmarks, buttons, and links so controls have recognizable purpose. Give form fields programmatic labels and explain errors in text, not color alone.

Check text contrast, zoom and reflow, touch target spacing, and whether instructions remain clear when motion or animation is reduced. Add text alternatives for meaningful images; decorative images should not create noise for screen readers. Captions are needed for relevant prerecorded video content.

## Test with real tools and people

Automated checks can find some issues but cannot establish accessibility. Pair them with keyboard checks, at least one screen reader pass, and feedback from people with relevant access needs when feasible. Fix barriers in the task’s main path before polishing low-priority pages.

The [W3C WCAG 2.2 understanding documents](https://www.w3.org/WAI/WCAG22/Understanding/) explain success criteria and intent. Conformance requires evaluating the complete applicable criteria at a chosen level; this checklist is a practical starting point, not a claim of conformance.

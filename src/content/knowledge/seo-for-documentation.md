## Make pages genuinely useful

Give each page a clear title that describes the task and a concise summary that helps a reader choose it. Answer the main question early, then provide enough context, steps, limitations, and sources to make the guidance useful. Link related concepts with descriptive anchor text. Avoid creating near-duplicate pages to target tiny keyword variations.

## Make the site discoverable

Use crawlable links, stable URLs, descriptive headings, canonical URLs, a sitemap, and a robots file that does not block intended pages. Ensure the page is readable without client-side rendering where possible. Keep metadata accurate and do not mark draft or search pages as indexable content. Add structured data only when it accurately represents visible content.

SEO cannot guarantee rankings. Indexing and appearance depend on search systems and competing material. Check Search Console after the site is publicly reachable and fix crawl or canonical issues it reports. Follow [Google Search Central’s developer guide](https://developers.google.com/search/docs/fundamentals/get-started-developers) and its [sitemap guidance](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap).
